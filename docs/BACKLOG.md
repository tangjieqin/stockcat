## 2. 明确不做（想清楚了，别再讨论）

| 决定 | 原因 |
|---|---|
| **AI 自动写正式复盘** | 草稿必须经人确认才转 `MANUAL`，这条不放开 |
| **多轮对话与长期记忆** | 前端有会话列表（localStorage），后端保持无状态。加上下文会让"数据来自哪次查询"难以追溯 |
| **AI 写业务数据** | 只能写复盘/日记草稿，且必须由用户点保存 |
| **AI 回答里自述出处** | `citation` 只认后端按真实 `seq` 拼的，模型写的出处一律删（`library_guard`） |
| **数据源"尽力而为"** | 未验证的渠道不接；宁可显示"数据源不可用"，也不给假数据 |
| **多用户与消息队列** | 个人本地项目 |
